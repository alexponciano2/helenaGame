# HelenaGame

Projeto de plataforma 2D criado com Unity `6000.6.0f1`.

## Abrir em outro computador

1. Instale a Unity `6000.6.0f1` pelo Unity Hub.
2. Clone este repositório.
3. No Unity Hub, escolha **Adicionar projeto do disco** e selecione a pasta clonada.
4. Aguarde o Package Manager restaurar as dependências de `Packages/manifest.json`.
5. Abra `Assets/Scenes/SampleScene.unity`.

As pastas `Library`, `Temp`, `Logs`, `obj` e `UserSettings` não são versionadas; a Unity as recria automaticamente.

## KitWright MCP / Codex

O pacote KitWright MCP está declarado no projeto. Em um computador novo:

1. Abra **Window > KitWright > MCP Window**.
2. Inicie o servidor.
3. Selecione **Codex** e execute **Configure + Skills**.

O endereço MCP local não é versionado porque a porta e o identificador podem mudar entre computadores.
